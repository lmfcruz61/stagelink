Guia rapido de operacao

Usa este guia conforme o teu papel: artista, manager/equipa ou admin.

Artista

  1. 1. Completa a pagina.
    Adiciona capa, foto principal, frase de destaque, cidade, bio e links.
  2. 2. Cria a galeria.
    Mostra palco, bastidores, ensaios, cartazes ou momentos com o público.
  3. 3. Escolhe o tipo.
    Marca o evento como ao vivo, estreia, video gravado ou replay para nao mostrar "Ao vivo" quando nao for direto.
  4. 4. Agenda o espetáculo.
    Usa uma capa 16:9, data, preco e ID/link YouTube com incorporacao ativa.
  5. 5. Testa a sala.
    Confirma countdown, player, badge do estado, marca do artista, chat e botoes de apoio.
{% if can_manage_organizations %}

Manager / equipa

  1. 1. Cria a equipa.
    Usa "Nova equipa" para agencia, produtora, label ou management.
  2. 2. Adiciona artistas.
    Cria paginas em "Novo artista gerido" e associa cada uma a equipa certa.
  3. 3. Gere permissoes.
    Adiciona membros por username como dono, manager, editor ou leitor.
  4. 4. Opera por artista.
    Seleciona o artista no dashboard antes de editar pagina, criar espetáculo ou consultar resultados.
  5. 5. Atualiza replays.
    Depois de um evento, muda o tipo para replay quando o video continuar disponivel para publico ou subscritores.

Admin

  1. 1. Configura o site.
    No admin Django, define logotipo, imagem de fundo e overlay em Aparencia do site.
  2. 2. Verifica contas.
    Confirma users, perfis, artistas, equipas, membros e permissoes.
  3. 3. Testa acesso livre.
    O admin deve conseguir entrar em qualquer espetáculo sem subscricao nem bilhete.
  4. 4. Monitoriza operacao.
    Confirma pagamentos em modo teste, chat, uploads, estados dos eventos e logs do Fly.io.
